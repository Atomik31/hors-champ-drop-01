# DESIGN.md — HORS CHAMP / Drop 01

Direction : **Quiet utility × worn precision**

## Palette
| Token | Hex | Usage |
| --- | --- | --- |
| Chalk | #E8E7E2 | fond clair, texte sur fond sombre |
| Carbon | #151515 | fond sombre, texte |
| Concrete | #898985 | texte secondaire, filets |
| Steel | #B8BBB7 | surfaces, placeholders |
| Signal | #D6FF3F | accent unique (CTA, détails réfléchissants) |
| Rust | #8D4936 | accent rare, patine |

## Typographie
- Titres : sans-serif condensée forte (Archivo Narrow / Oswald), uppercase
- Textes : sans-serif neutre (Inter)
- Labels : monospace uppercase (JetBrains Mono)

## Image
Silhouettes en mouvement, cadrages partiels, détails de matière, flash direct
ou lumière froide, béton / métal / bitume. Imperfections visibles.
Aucune image réelle fournie : placeholders visuels (grain, gradients), jamais
présentés comme des photographies de la marque.

## Principes
- Calme, précis, éditorial, mobile-first.
- Ni SaaS, ni e-commerce générique, ni luxe classique.
- Aucun faux stock, faux prix, faux avis ni fausse urgence.
